Parts in the current prototype pod (3D-printed enclosure).

| Item | Status |
|---|---|
| ESP32 module | ESP32 Dev Module, original 38-pin |
| I2S microphone | INMP441 (24-bit sample in a 32-bit word, scaled by `mic_shift` from the hub) |
| Display | SSD1306 0.96" OLED, 128x64, I2C |
| Power source | TBD |
| Pocket router | TBD |
| Laptop for the hub | Any machine that can run the low-spec profile (8 GB) or the stronger profile |

The hub laptop is not part of the pod enclosure. It runs the Python hub on the same Wi-Fi network.
